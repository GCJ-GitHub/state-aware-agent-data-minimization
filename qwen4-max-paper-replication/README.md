# Qwen4-Max 论文实验复现

本轮用 Qwen4-Max 网关别名复跑论文核心结果及用于解释核心结果的两项消融。任务、状态更新、各组规则、工具格式、种子与预算使用原冻结版本。保留原实验关闭推理的设置。五项正式实验共 2,736 个运行。

| 实验 | 运行数 | 回答的问题 |
| --- | ---: | --- |
| 强基线自主对照 | 720 | 读前刷新路线表与版本化契约后端的减曝、恢复和开销 |
| 三组自主对照 | 1,080 | 事前给齐、Agent 自行按需、后端按状态校验的差异 |

| 文本工具消融 | 144 | 相同因素在原文本工具调用协议下的影响 |

早期调试轮次、其他模型评测和纯问答的历史实验可在历史档案里查阅。离线复跑另覆盖必要性原型、退款示例、物流组合、流程依赖、签收核验、维护与日志、误配归因。离线结果与原档案逐项核对，其调用模型数为零。

## 运行与检查

在仓库根目录执行。网关 URL 和仓库外凭据文件通过 STUDY_GATEWAY_URL、STUDY_KEY_PATH 提供。STUDY_EPHEMERAL_KEY=1 会在读入后删除临时凭据文件。每条运行记录原子写入。重启会跳过已经完成的记录。传输错误保留。传统运行器在遇到接口错误时会尽量重建实际收到的前缀，再用原有计分规则评分。若事前筛选回复不足以构造运行，标记为未评分并保留在分派人数内。

    python qwen4_paper_replication.py run
    python qwen4_paper_replication.py summarize
    python qwen4-max-paper-replication/analyze.py

freeze.json 记录设计和输入哈希。summary.json 记录各臂分母、业务结果、字段交付、泄露与调用开销。paired-analysis.json 在每个实验完成全部分派后才生成正式配对差和区间。offline-audit.json 保存不依赖模型的复跑核验。adapter-preflight.json 保存原有四种工具协议在新运行器下的离线重放验证。

## 论文中的比较口径

- 业务动作正确、安全停止、最终回复和达到预算分开报告。
- 强基线额外统计流程关闭以后的工具调用。可以结合两项调用数看出后端恢复与结束判定分别消耗多少。
- 同模型下用相同任务和种子比较后端。跨模型比较也按这些索引匹配。任务对聚类保留同一对的状态变体和全部重复。
- Qwen4-Max 是服务返回的模型别名。权重版本和随机种子实现由服务端决定。
