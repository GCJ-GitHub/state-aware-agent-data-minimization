# Qwen4-Max 自主工具调用试跑

复用已经冻结的强基线自主对照。在三个任务家族中各取一个路线变化用例和一个仅更新版本的用例，固定种子 19。六个任务分别运行路线表和契约后端，共 12 次。对比 Qwen3.8-Flash 档案里同任务、同后端、同种子的 12 条记录。两种模型使用共用提示、授权、工具、状态时钟和 40 轮预算。本次 API 调用显式关闭推理模式，沿用每轮 512 输出 token 上限。这个样本用于检查模型兼容性和发现失败模式。

| 指标 | Qwen3.8-Flash | Qwen4-Max |
| --- | ---: | ---: |
| 正确业务结果（含安全停止） | 12/12 | 12/12 |
| 多读字段 | 0 | 0 |
| 原值出现在可见文字的运行 | 0 | 0 |
| 正常生成最终回复 | 12/12 | 5/12 |
| 达到 40 轮上限 | 0 | 6 |
| 因网关错误结束 | 0 | 1 |
| 工具调用 | 158 | 340 |
| 业务已结束后继续发起的工具调用 | 22 | 204 |
| 模型响应 | 171 | 345 |

Qwen4-Max 在这批用例里完成了业务动作，但有七次在完成业务后触及轮次预算或接口中断。现有接口在工作流结束后对工具调用返回通用检查失败，工具调用多出的部分主要发生在这一阶段。需要分开报告业务结果和正常对话结束。

成本与模型的交互由这套工具协议、预算和提示共同决定。样本量用于试跑。若做第二模型复现，可先用开发集核验统一的终态回包，再在新冻住的任务上比较两种后端。脚本化维护、规则误配、静态回归和日志重建均无需调用模型。
