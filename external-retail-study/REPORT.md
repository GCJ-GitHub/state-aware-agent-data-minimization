# 独立零售工具环境中的三组对照

以 Sierra τ-bench 零售测试集的 12 条人工任务作为来源，抽取 15 个不同目标订单，每个订单构造一对状态变体，得到 30 个任务。三组各重复 3 次，共 270 次，均完成离线重放。模型为 MaaS Qwen4-Max，沿用相同授权、确认、反馈和预算。

[冻结的上游代码与任务](https://github.com/sierra-research/tau-bench/tree/59a200c6d575d595120f1cb70fea53cef0632f6b/tau_bench/envs/retail)

## 独立性与边界

- 上游提供合成订单、人工标注的退货参数和部分取消订单操作。读取订单、改址、退货和取消操作执行固定提交里的原工具代码。
- 本研究构造初始待处理状态、统一的备用地址、条件式授权和送达时钟。用户对话采用固定请求和模拟确认。因此本轮评估是把交付机制迁移到独立工具和基准任务材料上的控制实验。任务对和中途扰动仍由本研究设计。
- 工具回包只对 Agent 展示所需投影。多读以交付时当前路线为准，退货商品编号列表按一个字段计。正文原值匹配覆盖模拟地址首行、支付方式编号和商品编号，范围限于可见文字。
- 时钟安排在公共状态或首笔操作提交之后的固定模型轮次。所有运行进入分母，同时报告实际发生在准备与交付之间的例数。

- Agent 自行按需，命中取数窗口 45/45 次，安全停止 15/15，可见原值匹配 0 次，网关中断 0 次。
- 读前刷新路线表，命中取数窗口 45/45 次，安全停止 15/15，可见原值匹配 0 次，网关中断 0 次。
- 契约后端，命中取数窗口 45/45 次，安全停止 15/15，可见原值匹配 0 次，网关中断 0 次。
