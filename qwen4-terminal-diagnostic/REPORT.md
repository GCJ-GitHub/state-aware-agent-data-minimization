# Qwen4-Max 的工作流结束反馈诊断

本诊断从正在执行的强基线复现中选出六个已有两组配对记录的任务。筛选只看任务家族、状态变体、种子和存档是否齐全，排除最早的兼容性试跑任务，未按结果筛选。每个任务分别在路线表和契约后端复跑，重用任务、种子、工具、初始提示、授权、确认、恢复规则与预算。

唯一的协议变化发生在业务已经结束之后。已有工具错误回包改成明确的工作流已结束状态，并提示 Agent 给出简短最终回复。所有业务调用仍由模型发起。系统没有提前截停模型。

| 指标 | 原关闭回包 | 明确关闭回包 |
| --- | ---: | ---: |
| 正确业务结果 | 12/12 | 12/12 |
| 多读字段 | 0 | 0 |
| 正常最终回复 | 4/12 | 12/12 |
| 工具调用 | 361 | 144 |
| 其中业务关闭后发起 | 225 | 8 |
| 业务关闭前发起 | 136 | 136 |

总工具调用减少 217 次，差值全部来自业务关闭后。该小样本验证了协议对结束行为的影响，模型在这批任务上的业务结果与字段交付持平。该诊断的记录是补充结果，主复现采用原先冻结的反馈和预算继续运行。
