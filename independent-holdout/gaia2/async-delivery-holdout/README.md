# Gaia2 异步交付三组对照

## 公开任务与冻结边界

本轮选五道 Gaia2 Adaptability 验证题。它们都含上游编写的购物订单取消和业务判分，未用于此前的字段策略或交付窗口调试。全量可达性运行已覆盖这些题。我们沿用原用户请求、原生工具、原生取消事件及其依赖、原业务判分。模型决定实际下单、汇报和后续行动。上游材料的快照和环境版本见 [DATA.md](../DATA.md)。本轮五题均来自购物，源任务还涉及通知、邮件或日历。

正式的 Async-RBench 事件调度和隐藏判分未随公开任务包提供。Gaia2 可以固定业务任务、事件与判分，但购物取消依赖上游的用户汇报事件，公开题没有为我们选定的字段安排在途读取。因此本研究添加通用的挂起读取适配，在首次成功结账前准备一个真实的目录标识或已用折扣码。后台线程监听指定的上游取消事件，挂起读取在原生取消后只随工具回包交付一次。三组共享这一安排。字段判分是本研究的另外一层，和原生业务成功分别计分。

| 题号 | 原生取消后的任务 | 挂起字段 | 字段标签 |
| --- | --- | --- | --- |
| 0631 | 用下一档优惠重新购买 | 原订单用过的精确折扣码 | 原路线上使用过，切换后不再允许交付 |
| 0879 | 原商品继续购买，调整数量 | 黑蛇商品的目录 ID | 当前路线仍允许 |
| 0941 | 重购原商品并处理追加购买 | 扑克牌的目录 ID | 当前路线仍允许 |
| 0947 | 同款商品改用更高价的变体 | 商品级目录 ID | 首次购物取消后仍允许 |
| 0949 | 使用下一档优惠或无优惠重购 | 原订单用过的精确折扣码 | 原路线上使用过，切换后不再允许交付 |

五题在同一 Qwen4-Max 环境下每组重复三次，共 45 个分派。三组只切换这一条挂起读取的判定。读准备组沿用准备时的判断，交付前路线表按当前路线刷新，窄契约在执行同一交付检查时还比较所绑定的授权代数和字段标识。公开题中的授权代数固定。对目录 ID 和优惠码标识，以原生值标识进行绑定，本轮没有独立的撤权重授或同值回写试验。判分使用冻结的 [gold.json](gold.json)，后端本身使用 [protocol.json](protocol.json) 记录的路线和字段用途。运行器、规则、判分及已有组件哈希一起冻结。

## 统计口径

- **成功且多读**以原生业务判分通过且旧值再次进入模型输入为事件。分别报告所有成功、所有已分派及同题同种子三组均命中回包窗口的分母。
- **误拒绝**以当前路线仍允许精确字段时返回拒绝为事件。只在模型实际收到回包或拒绝后计分。此前已送达的值不会被抹掉。
- **恢复开销**为该回包或拒绝之后，Agent 发起的原生工具调用，不计公共的挂起读取。分别报告所有已交付决定的调用、仅被拒后的调用和三组匹配差。
- **延迟**分开统计取数准备到回包、上游汇报工具完成到附加回包，以及后端判定时间。前两项包含等待原生事件或模型推理等调度成本，后端判定计本地 Python 时间。
- **适用范围**为公开工作流上的受控异步交付。迟到的重复原值是观察对象。该设计不估计自然交付窗口发生率、跨服务事务原子性或对外披露。当前允许的商品 ID 是路线范围判定，是否可直接复用此前已经入上下文的 ID 是单独问题。

## 复核

在仓库根目录执行以下命令。在线运行沿用 [Gaia2 数据及依赖说明](../DATA.md)，所需模型凭据通过本机环境提供。

```bash
shasum -a 256 -c independent-holdout/gaia2/async-delivery-holdout/FREEZE.sha256
python independent-holdout/gaia2/async-delivery-holdout/run.py \
  --parquet /path/to/adaptability.parquet --verify-only
python independent-holdout/gaia2/async-delivery-holdout/summarize.py \
  independent-holdout/gaia2/async-delivery-holdout/results.jsonl
```

线上重复运行时，请为 `run.py` 提供独立的 `--output` 路径和 `--workers 6`。冻结规则中有并发分派顺序和预算说明。

`EXECUTION_FREEZE.sha256` 保留原始执行指纹。`FREEZE.sha256` 核验公开仓库中的文件。共用 Gaia2 环境的旧运行入口在发布时已把网关地址移至环境变量。本轮新代码、冻结规则、字段标签和结果保持执行时的字节。
